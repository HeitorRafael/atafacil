# Instruções do Projeto Atafacil

## Antes de Começar
1. Instale dependências: 
   - Backend: `cd server && npm install`
   - Frontend: `cd client && npm install`
2. Configure `.env` (copie `.env.example` se existir) em ambas as pastas
3. Inicie dev:
   - Backend: `npm run dev` (na pasta server)
   - Frontend: `npm run dev` (na pasta client)

## Padrão de Commits
- `feat: descrição` - nova funcionalidade
- `fix: descrição` - correção de bug
- `docs: descrição` - documentação
- `style: descrição` - formatação
- `refactor: descrição` - refatoração
- `chore: descrição` - tarefas auxiliares

## ⚠️ IMPORTANTE - ATUALIZAÇÃO DE PORTFÓLIO
Após CADA commit significativo (não inclua `style:`, `chore:` menores):
1. Edite `.project.md` e atualize seção "Última Atualização"
2. Atualize o % de "Progresso" se houver mudança de escopo
3. Faça o commit do projeto normalmente
4. Rode `python AgenteMestre/sincronizar_portfolio.py` para atualizar o Portfolio

## Scripts Disponíveis
```bash
# Backend
npm run dev      # Inicia servidor em modo desenvolvimento
npm run build    # Build para produção
npm run test     # Executa testes

# Frontend
npm run dev      # Inicia dev server
npm run build    # Build para produção
npm run preview  # Preview do build
```

## Regras de Desenvolvimento
- Sempre fazer branch antes de mudanças grandes
- PRs devem referenciar issues quando aplicável
- Testar localmente antes de commit
- Manter `.project.md` atualizado com progresso real
- Backend e Frontend versionam juntos (mesmo commit)
